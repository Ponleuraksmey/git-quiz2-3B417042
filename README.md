題目：簡易消費紀錄統計系統
請使用 Python 設計並實作一個簡易的消費紀錄統計系統，讓使用者記錄消費項目與金額，並查看消費明細及統計結果。

系統提供「新增消費、顯示消費明細、顯示統計、退出系統」四個功能。
使用 while 迴圈顯示主選單，完成操作後回到主選單，直到使用者選擇退出。
每筆消費使用一個 dict 儲存，包含「項目」及「金額」，並使用一個 list 管理所有消費紀錄。
使用 input() 接收輸入。確認金額格式正確後，轉換為 float 再儲存。
使用 for 迴圈讀取消費紀錄，使用 f-string 或 format() 格式化輸出。
程式命名及縮排應符合 PEP 8 的基本要求。
需求
1. 新增消費（25 分）
使用者輸入消費項目與金額，例如「午餐、100.5」。

金額可以是整數或小數，但必須大於 0。
金額使用半形數字及小數點輸入，例如 100、100.5、0.5。
輸入文字、空白、多個小數點、零或負數時，顯示錯誤提示，並要求重新輸入金額。
輸入錯誤時不得新增資料，也不必重新輸入消費項目。
新增成功後顯示「新增成功」，並回到主選單。
同名項目可以重複新增，每次新增都視為一筆獨立的消費。
本題可假設消費項目不為空白。不必支援千分位逗號、貨幣符號或科學記號。

輸入檢查提示

不需要使用例外處理。可以先用字串方法檢查，再轉成數字：

strip()：移除輸入前後的空白。
replace(".", "", 1)：移除第一個小數點，供後續檢查使用，不改變原本的輸入字串。
isascii() 與 isdigit()：一起使用，可檢查剩下的內容是否只包含半形數字 0～9。
例如 100.5 移除第一個小數點後是 1005；1.2.3 移除第一個小數點後仍有小數點，因此不是有效格式。

格式正確後，仍須確認金額大於 0。

2. 顯示消費明細（25 分）
使用 for 迴圈逐筆顯示所有消費紀錄。

欄位依序為「編號、項目、金額」。
編號從 1 開始，依新增順序顯示。
金額顯示至小數點後兩位。
欄位須清楚排列，數字欄位靠右對齊；不要求處理所有中文字寬的差異。
如果沒有資料，顯示「目前沒有消費紀錄」。
3. 顯示統計（30 分）
根據目前所有消費紀錄，顯示：

消費筆數。
總金額，顯示至小數點後兩位。
平均每筆金額，顯示至小數點後兩位。
依照總金額顯示以下訊息：
總金額	顯示訊息
未滿 300 元	消費不多
300 元以上，未滿 500 元	注意控制消費
500 元以上	已達提醒門檻
計算及判斷使用儲存的金額，只在輸出時格式化為小數點後兩位。

如果沒有資料，只顯示「目前沒有消費紀錄」，不進行平均計算。

4. 主選單與退出系統（10 分）
輸入 1～4 執行對應功能。
輸入其他內容時，顯示「選項錯誤，請重新選擇」，並重新顯示主選單。
選擇退出後，顯示「系統已退出」，並結束程式。
5. 程式可讀性與繳交內容（10 分）
使用有意義的變數名稱及一致的縮排。
GitHub 專案包含程式碼、執行說明及執行結果截圖。
